# Hytale Recipe Browser (Too Many Items)

A crafting guide plugin for Hytale. This plugin provides a interface for players to explore every crafting recipe, organized by workbench, tier, and material requirements.

## Features

* **Workbench-Specific Navigation:** Filter recipes by their respective workstations (Armorer's Workbench, Alchemist's Table, Anvil, etc.).
* **Search Functionality:** Quickly find any item or material using the search bar.
* **Tier & Requirement Tracking:** View exactly what tier is required and which ingredients are needed for every craftable item.
* **HUD Recipe Pinning:** The ability to "pin" a specific recipe to your screen. 
    * This will track your progress in real-time.
    * Dynamic checklist: `Iron Bars (2/5)` - automatically updates as you collect materials.
* **Ingredient Tooltips:** Hover over ingredients to see where they are found or how they are processed.
*

## Overview

This plugin is developed in **Java** utilizing the Hytale modding API.

### Requirements
* Hytale Game Client/Server
* Java 25 (or the version required by the Hytale SDK)

## Installation

> *Note: Since Hytale is still in development, installation steps are subject to change based on the official release.*

1.  Download the latest `.jar` release.
2.  Place the file into your server's or client's `/mods` directory.
3.  Launch Hytale and type `/recipes` in the chat to see the menu.
